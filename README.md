# JavaScript Basics Practice

Repository ini berisi kumpulan latihan dan catatan kode selama mempelajari dasar-dasar pemrograman JavaScript.

## Daftar Materi
- **Minggu 10:** Variabel (`const`, `let`), Tipe Data, Fungsi, Kondisi (`if/else`), dan DOM Selection.
- **Minggu 11:** *(Coming soon)* Event Handling & Manipulasi DOM.

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka file `.html` menggunakan browser atau ekstensi **Live Server** di VS Code.
3. Tekan `F12` dan buka tab **Console** untuk melihat output JavaScript.
